# 手机端历史版本

保留 0.2.5、0.3.0、0.4.0 三个关键节点，从当时的本机 MMPKG 提取手机端发布文件，供代码比较与功能回溯。

| 版本 | 阶段 |
| --- | --- |
| 0.2.5 | 模型接入与流式反馈 |
| 0.3.0 | 主持人场景与 v0.5 需求适配 |
| 0.4.0 | 自动说话人角色与访谈总结 |

各目录的 ARCHIVE.md 记录提取范围与脱敏处理，provenance.json 记录原包哈希。原包声明的文件哈希均核对通过，归档中已移除个人访问码。

这些目录不构成对应版本的完整工程，不包含当时后端和测试，不是安装包，也不挂旧版本标签。当前完整项目的版本标签为 v0.4.1，对应提交 39fec26。
