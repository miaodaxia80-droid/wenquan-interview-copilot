# 问全·实时访谈助手

帮助主持人在认真听回答的同时，抓住值得追问的细节，并在访谈后整理带出处的素材。

## 当前版本 0.5.5（2026-10-17）

确认提纲后，眼镜立即显示可选主线问题；收到回答后，优先展示有依据的追问或转场，主问题已回应且暂无候选时补上下一条主线建议。无新语音时保留建议，不因沉默自动跳题。已问但未收到回答时保留待答提醒，展示不会自动记为已问。眼镜新增章节位置、下一条主线与“建议 · 自由选择”。详见 [主线建议与眼镜显示验收](docs/主线建议与眼镜显示_0.5.5_2026-10-17.md)。

修复真机“storage item exceeds 64 KB”导致访谈无法保存：旧版把全部主题、转写和分析放入一个存储项，现改为安全大小的 JSON 分块和双组快照，全部分块写完才提交索引。兼容读取旧版记录；保存失败持续显示警告，可重试或导出当前访谈。详见 [存储容量修复与验收](docs/存储容量修复_0.5.4_2026-10-17.md)。

**升级前先保护未保存内容**：旧版手机仍停留在报错页面时，不关闭或刷新；点页面内“返回访谈”→底栏“记录”→“导出 Markdown”，核对完整原话后再扫码更新。新版可迁移已经落盘的旧数据，无法自动找回关闭旧页面后丢失的内存内容。

新增 **AIdol 选手快访**：默认 7 分钟、五条主线，覆盖项目与演示、痛点与起因、方案与取舍、困难与攻克、验证与下一步。有困难追问尝试与结果；暂无明显困难则了解顺利的原因和未验证的环节。每条主线先问一个主问题，按回答选择追问。5–8 分钟是主持人的节奏建议，不会自动结束录音。详见 [AIdol 现场快访提纲与验证](docs/AIdol选手快访_0.5.3_2026-10-17.md)。

手机 UI 已按独立浅色原型更新：微绿白底、翠绿主色、三项底栏、当前问题卡及会中四键操作条。原有业务入口保留，详见 [浅色手机 UI 验收](docs/浅色手机UI_0.5.2_2026-10-17.md)。浅色版改造前包保留在 `release/before-light-ui/`，当前安装包为下方 0.5.5。

产品统一更名为 **问全·实时访谈助手**。访谈主题页移除体验示例入口，提供六个可直接使用、自由编辑的访谈模板。眼镜在已开始访谈时提供主线、追问、转场或收尾建议；已问待回应时保留问题，暂停或结束时关闭显示。

| 模板 | 计划时长 | 访谈主线 |
| --- | --- | --- |
| AIdol 选手快访 | 7 分钟（建议 5–8 分钟） | 项目与演示、痛点与起因、方案与取舍、困难与攻克、验证与下一步 |
| 人物经历 | 30 分钟 | 起因、关键选择、最大困难、回看与建议 |
| 用户研究 | 25 分钟 | 触发与目标、实际过程、阻力与替代、结果与取舍 |
| 需求澄清 | 40 分钟 | 真实流程、规则与例外、第一版范围、资料与系统、验收与推进 |
| 项目复盘 | 30 分钟 | 目标与结果、关键节点、有效与受阻、下次怎么做 |
| 专业观点 | 30 分钟 | 问题与概念、判断与依据、案例与分歧、边界与行动 |

每个模板预填主题、访谈目标、计划时长、主线和可编辑的问题；不预填嘉宾回答。使用模板新建独立访谈，保留现有记录。当前自动检查 131/131 通过；原有开箱模板与待机的历史验证见 [0.5.2 开箱模板与待机验收](docs/开箱模板与待机_0.5.2_2026-10-17.md)。

## 使用与安装

1. 在“访谈主题”选择模板，修改主题、目标与提纲，补充嘉宾背景或访谈边界。
2. 获得对方同意记录后开始访谈。开场自然说明双方角色；流式 ASR 与模型结合语境判断主持人和嘉宾，不确定的片段保留待识别，完整转写支持人工更正。
3. 会中先听回答，眼镜显示一条可选建议和主线上下文。实际自拟问题也可记录，已问与已回应分别管理。
4. 点击“结束并整理”，生成整场核心内容、按主线归纳与待补问；要点带嘉宾原话出处，章节摘要可编辑并导出 Markdown。

## 开发与运维

```sh
npm ci
npm run check
npm run build
npm test
npm run start:studio
```

Node.js >=22。唯一编辑源为本项目 `web`，构建自动更新 `dist`、MMPKG 和相邻 PhoneSDK 中的问全镜像；不改 SDK 公共实现。Studio 开发服务只监听 `127.0.0.1:8790`，不能用于公网。正式网关使用 `server/service.mjs`，容器仅映射服务器回环地址，现有 Caddy 提供 HTTPS/WSS。

模型与 ASR 配置沿用服务器 `.env`，不打印、不打进源码包。新环境参考 `.env.example` 及 `profiles/volc-agent-plan.env.example`；当前文本模型为 Agent Plan DeepSeek V4.1 Flash，ASR 为豆包流式 2.0。流式转写主路径不依赖服务器 ffmpeg；旧 HTTP 文件转写兼容接口不在云端支持范围。

```sh
node --env-file-if-exists=.env scripts/verify-interview-0.4.mjs
node scripts/verify-interview-0.4.mjs --cloud
WENQUAN_GATEWAY_URL=https://cx.kevinxu.cn/wenquan node --env-file=.env.cloud scripts/probe-cloud-0.4.mjs
```

这些探针会真实调用现有服务额度，测试内容为虚构文本或系统合成声音。主路径为连续采集、WSS 识别、角色判断、实时分析；原始音频不存到问全后端磁盘，本地保留完整转写。会后归纳读取整场转写，长内容分块整理后合并，最多 1500 段 / 24 万字符，超限明确提示，不静默裁剪。

源码说明：`web/intelligence.js` 负责角色及归纳引用校验，`server/intelligence.mjs` 负责模型识别和整场整理，`web/interview-ui.js` 负责精简后的主持人界面；原有转写、状态、权限和显示链路继续使用。

部署、备份和回滚见 [deploy/README.md](deploy/README.md)。历史状态见 [0.3.0 README 存档](docs/README_0.3.0历史.md) 与各版本验收文档，不能当作当前版本结果。
