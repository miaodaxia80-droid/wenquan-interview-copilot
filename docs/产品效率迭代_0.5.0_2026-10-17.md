# 问全 0.5.0：访谈效率迭代

日期：2026-10-17。源代码基于本地 0.4.1 工作区，未提交或推送。本轮以降低现场操作负担、减少重复提示及提升会后查找效率为目标。

## 已实现

- 现有候选增加 keep/superseded 有效性核对，撤下过时问题不冒充已经回答。已回应与新候选同一响应时，过滤相同问题或相同信息目标；相同信息目标换措辞也会过滤。模型仍负责语义判断，程序的文本规范化并非通用语义去重。
- 当前问题优先保留阅读稳定性；每次分析时收起超过60秒未复核的候选。60秒是初始策略，非戴镜验证结果，也不是独立的定时清空承诺。
- 稳定语音按最多16段、24000字符批次处理，每段原文、角色、来源和顺序独立保留。同批次自拟问题和后续回答可关联；处理期间收到新发言时保留事实但收起过时候选。历史角色重新识别仍可能产生多组分析，尚未做长时压力测试。
- 健康信息缓存60秒；保留未知角色处理及修正后旧分析失效规则。
- 眼镜使用模型生成的28字以内独立短问句；手机保留完整问题与依据。无候选时清空显示。旧结果缺短提示时仅截断回退，不将回退称为语义压缩。
- 会中候选备选、补记已问、主线调整和分析进度默认折叠；异步刷新保留已打开面板及输入草稿。
- 准备页可粘贴每行一条的纯文本提纲，追加而不覆盖原主线；支持预计时长，已有优先级3用于必聊项。主题首页演示入口折叠。
- 会后新增素材索引导出，保留完整记录导出。索引包含核心内容、出处、人工章节摘要及待补问。采集时间按每次录音流编号，明确不等同外部视频时间码。
- 记录稳定ASR到图像两块均获显示确认的间隔，保存最近200个问题的送达指标；失败不记送达。该指标不包含从实际说话结束到ASR稳定的时间，也不证明用户已读到镜片。
- 新版录音启动前检查网关批次能力，旧网关时明确阻止启动。
