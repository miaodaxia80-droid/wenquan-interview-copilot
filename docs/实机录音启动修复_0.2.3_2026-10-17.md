# 0.2.3 录音启动修复与验证

日期：2026-10-17。手机插件 0.2.3，云端网关继续使用 0.2.1。

用户报告：实机点击“确认清单，开始录音访谈”后仍停在准备清单页，按钮没有变化。这个现象发生在打开 ASR 之前；不能直接认定是云端凭证或火山服务故障。

## 已确认的代码问题与修复

- 旧流程先等待存储，再切换页面；并在启动录音前等待眼镜显示。存储拒绝、宿主无响应或显示迟迟未完成时，准备页没有及时反馈。现在按钮立即显示确认中，校验通过即切换访谈页，眼镜同步异步进行，采集不再等待显示。
- 原生表单 required 校验在部分嵌入式环境中提示可能不可见。现在显式处理按钮点击和键盘提交，统一校验目标、角色及完整事项；错误持久显示在按钮上方。
- 保存清单失败会阻止录音，并在访谈页顶部保留原因；宿主能力、云端检测、ASR 连接、打开麦克风、等待音频各有可见状态。宿主调用有超时，首次音频等待 8 秒后失败会关闭连接并提示检查眼镜、权限和占用。
- 避免依赖 structuredClone、Array.findLast、Array.at、Object.hasOwn、crypto.randomUUID 和 AbortSignal 的较新静态方法；改用兼容实现。手机确切 WebView 报错尚待实机日志确认，不将兼容性推断写为已证明根因。
- 停止、取消、错误会清理连接、读取器与采集；重复清理不会重复调用原生停止。停止后的状态不再残留“正在转写”。

云端地址与个人网关访问码继续随生成包预置；上游 ASR/模型 API Key 只在服务器。未重新部署云端，未切回手机内置 ASR。

## 本轮已完成的检查

- JavaScript 语法检查通过；50 项自动测试通过，见 `evidence/test-results-0.2.3.txt`。
- 新回归测试执行实际 app.js 点击处理，覆盖眼镜显示永久等待、空事项、存储拒绝、缺少新 JS API、宿主永久等待与取消。
- 原生流测试覆盖连接取消、首帧超时停止、分块发送和尾包收尾。
- 原生 Studio 0.2.3：角色为空时点击确认可见持久校验错误；恢复角色后点击确认进入访谈页，显示连接进度，打开原生采集，接收音频并出现真实云端转写。短时测试后已点击停止。该测试使用桌面麦克风/模拟宿主，不等同 Android 或实体眼镜验收。
- SDK 官方组件配对检查通过。Studio 原样导出的 ZIP 包中手机与眼镜组件字节匹配，review 哈希一致。官方 ZIP 检查仍因其仅支持 review v1/v2，而 Studio 输出 v3 而失败；未修改检查器或审核文件。

## 更新及观察方式

用 Studio 当前 0.2.3 二维码覆盖更新，保留记录，无需卸载。打开后页脚应显示“问全 v0.2.3”。确认清单后应立即进入访谈页；如果不能继续，读取顶部持续显示的具体阶段和错误。安装包：`release/问全-0.2.3-Studio.zip`；手机组件：`release/wenquan-0.2.3.mmpkg`。
