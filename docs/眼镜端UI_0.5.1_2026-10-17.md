# 问全 0.5.1 · 眼镜端 UI

现场主持人需要在听对方讲话时扫一眼下一句。眼镜每次只呈现一个短问句，按单色 600×350、GRAY_4 输出。

## 设计

- 顶部左侧：真实候选类型（深入追问、补充细节、自然转场）；未知类型显示“可以追问”。
- 顶部右侧：候选问题所属主线，宽度超过 300px 时省略。不制造进度或计时。
- 正文：44px、500 字重；保持短问句上限 28 字，以实际字宽均衡换行。可用时利用中文分词边界，减少拆词；避免标点孤立在行首和拆开英文单词。极端字体宽度下缩小字号，代替截掉整行。
- 一至三行按内容高度居中，正文左右留 48px 安全空间。
- 底部：低亮度“问全”标记；离线脚本额外标注“离线演示”。
- 灰度：背景 #000，细线 #555，辅助文字 #888，类型 #bbb，主问句 #fff；最终发光颜色由设备决定。
- 暂停、结束、没有建议时全黑。保留原有两块 600×175 的图像传输及双确认机制。

实现：`web/glass-ui.js`；手机本地预览和眼镜投送共用此绘制函数。`design/glasses.html` 提供四种状态的交互预览，可切换原始灰度与模拟绿色，使用相同的产品绘制代码。

## 验收时修复

旧暂停逻辑在继续访谈时无条件开始录音。改为仅当同一访谈在暂停前处于录音或启动录音状态时恢复采集；文本演练只恢复提示。该意图保留在当前页面内，切换访谈后清除。
