# 问全 0.2.0 · 流式 ASR 接入与验收

日期：2026-10-17。范围：问全独立工程、官方 SDK 的问全生成镜像、本机后端和已登录的 MemoMind Plugin Studio。用户授权默认连续采集并改用火山 Agent Plan ASR，不再调用手机 App 内置 ASR。本次没有提交、推送或发布代码。

## 当前结果

主链路已实现并实际运行：原生采集 / 合成音频回放 → 本机 WebSocket → 火山豆包 ASR → 稳定分句入库 → JoyMaas DeepSeek-V4-Flash → 手机依据与追问 → GM Web Bridge v2 → 眼镜模拟器。

Studio 当前为问全 0.2.0，自动匹配官方 GM Web Bridge v2，并提示眼镜协议完全匹配。保留主题“火山流式回放 · 合成语音（虚构）”，显示真实模型问句“工单从进来到处理完成，经过哪些角色？”。本次回放结束、无录音进行中，待处理队列为 0，来源中有 1 段已分析转写。桌面端麦克风测试与合成音频测试分开记录，不把实际输入标成合成素材。

## 服务配置与选择

选择豆包流式语音识别 2.0 的双向流式优化版，使用 Agent Plan 专属路径：

- `wss://openspeech.bytedance.com/api/v3/plan/sauc/bigmodel_async`
- Resource ID：`volc.seedasr.sauc.duration`
- 后端 `X-Api-Key`，复用账户中现有套餐凭证。

本次在用户已登录 Edge 的“使用配置 → 语音模型”中复制现有凭证，直接写入本机忽略文件 `.env`，权限 600，并清空临时剪贴板。没有显示、提交或打包真实 Key；没有新建 Key、购买服务或开启超额后付费，也没有自动切换到非套餐接口。未核对实际账单、AFP 扣减数或价格。

采用约 200 ms 的分包；开启 `enable_nonstream` 二遍识别与 `show_utterances`，关闭 `enable_ddc`、`enable_itn`，保留标点。这些配置已被套餐端点实际接受。是否更准确需要独立语音样本评估，本次没有给出准确率结论。

ASR 负责音频到文字，语言模型负责目标对照、事项缺口、陈述和一条追问。文本模型继续使用已经配置并实测成功的 JoyMaas DeepSeek-V4-Flash。中间文字不逐字触发模型，稳定句串行分析。所有转写暂按当前手选角色标注，自动说话人分离尚未实现。

依据：[Agent Plan 接入语音模型](https://ark.volcengine.com/region:cn-beijing/docs/agent-plan-personal-voice-model)；[火山大模型流式识别 API](https://docs.volcengine.com/docs/6561/1354869?lang=zh)。本次通过 Edge 和官方公开 Markdown 查阅。

## 复验中发现并修复

1. 服务中间分句可用 -1 表示未知时间，最终/稳定分句也可能如此。旧校验会抛出“语音分句时间无效”。现在不让时间缺失阻塞文字：中间结果只预览，已稳定结果保存并去重；缺失时间明确提示、不生成虚假时间。相同无时间句被修订时返回更正，不重复追加。原生回放已复验。
2. 系统文件选择器关闭时可能尚未恢复前台，`files.openRead` 曾返回 NOT_FOREGROUND。现在等待生命周期并仅重试这种暂态拒绝，真正的权限错误不吞掉。文件已通过原生选择器重新导入并回放成功。
3. Studio 刷新时曾出现窗口空白，或生命周期显示 running 但存储仍 NOT_FOREGROUND。处理为恢复完成前锁住编辑与保存，前台重试，避免默认空记录覆盖旧存储；卸载取消待办操作，不向旧代际写入。将 Studio 切回当前桌面后，旧主题和历史记录恢复。

## 使用边界与下一步

- 默认录音只在本次已开始的访谈内，前台采集；暂停、离开或后台停止，不是系统常驻录音。每次上限 1 小时，未做 1 小时耐久测试。
- 原始流不落问全后端磁盘，不提供完整原始录音归档；保存的是转写和来源。文件选择器的宿主副本另由 SDK 管理。
- 网络断开、SDK 丢帧、积压或超时会明确停止，不会拿离线脚本当成真实识别。后台取消可能不产生未稳定的尾句，已稳定记录会保留；需要完整收尾时先点击停止并等待。
- Android App、实体眼镜录音与蓝牙传输、真机生命周期、设备麦克风准确率、长访谈体验均未验证。当前服务器监听本机回环地址，手机接入需另行部署可达的 HTTPS/WSS 后端。
- 下一步以实体设备验证为先，再验证双人区分、口音噪声、模型误判和追问打扰程度。自动检查或一次演示不能替代这些结论。
