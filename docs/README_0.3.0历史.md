# 问全 · 主持人的实时访谈助手

当前开发版本 **0.3.0** 已按 [主持人场景需求 v0.5](docs/项目需求_v0.5.md) 实现会前主线、0–3 个候选问题、主持人问答状态及会后回看。**v0.5 是需求版本，0.3.0 是软件版本。** 旧 FDE、用户研究、自定义场景和本地历史记录保留。

本轮通过 81 项自动测试、六轮带角色标注的合成文本真实模型验证，以及原生 **MemoMind Plugin Studio** 手机预览与 GM Web Bridge v2 眼镜模拟器联调。详见 [0.3.0 开发验收记录](docs/主持人场景_v0.5开发验收_0.3.0_2026-10-17.md)。本轮没有部署云端，也没有更新实体手机或验证镜片佩戴；已部署云端仍按历史 0.2.5 记录管理。新主持人场景检测到旧网关时会保留原话并提示更新。

## 0.3.0 的主持人流程

- 会前填写主题、目标、带来源的可选嘉宾背景与边界；编辑、增删和排序主线，设置预设问题和优先级。模型草案需要主持人确认。
- 会中整理主线信息，提供 0–3 个不同信息目标的候选；深挖题有逐字原话，提纲题明确标注提纲依据。新结果保留当前阅读项，手机选择后眼镜一次显示一题，并提示其他候选数量。
- 每题独立记录候选、当前展示、已问待回应、已回应、稍后、跳过与替代状态；支持自拟问题。已问不等于已回应，章节仅由主持人确认结束。
- ASR 编号按采集流隔离，需绑定主持人 / 嘉宾；未绑定为未知。确认 host 的轮次可由模型识别实际问题，后续 guest 原话才可关联回应。编号接入和角色规则已实现，真实音频连续轮次仍待实机验证。
- 按主线保留带出处的累积信息；会后可编辑摘要、查看问题历史及完整原话、导出 Markdown。结束后的原话可更正；更正会撤回派生分析，不自动继续现场分析。

## 在 MemoMind Plugin Studio 使用 0.3.0

1. `npm run build`；在原生 Studio 选择相邻的 `plugin-open-platform` 工作区，手机选择 **问全 · 主持人实时访谈助手 0.3.0**，眼镜选择推荐的 **GM Web Bridge v2**。
2. 在项目目录执行 `npm run start:studio`，开发服务只监听 `http://127.0.0.1:8790`。在问全“分析设置”选择真实模型、填写该地址、设备访问码留空并保存。本机 `.env` 负责上游配置；明确保存的 Studio 开发地址刷新后保留。
3. 新建“主持人访谈”，编辑主线后，可选“先用文本访谈”进行带角色文本联调；真实采集使用“开始录音访谈”。录音、暂停和结束行为需现场允许记录。
4. 最终组合包在 `release/问全-0.3.0-Studio.zip`，手机包在 `release/wenquan-0.3.0.mmpkg`。Studio 已保留“主持人 v0.5 联调 · 虚构访谈”的会后记录。

Studio 开发服务依赖本机运行，不能把手机的 127.0.0.1 当成 Mac 地址。个人包仍预置原云端连接，**云端升级到 0.3.0 前，新主持人场景不能直接通过该云端使用**；旧 v1 场景接口继续兼容。生产更新步骤见 [部署说明](deploy/README.md)。

组合包的声明配对预检通过，MMPKG/GMP 字节和 review 哈希核对通过。Studio 导出 review v3，而当前官方 ZIP 检查器只接受 v1/v2，因此官方 ZIP 审核附件检查未通过；没有修改检查器或审核附件，也不将字节核对视为签名或发布审核通过。个人安装包包含网关设备访问码，仅供本人使用；上游模型与 ASR Key 不在包内。

## 手机独立使用（0.2.5 免配置版）

1. 在 Studio 选择 **问全 · 访谈追问助手 0.2.5**，用当前二维码更新旧版；也可导入 `release/问全-0.2.5-Studio.zip`。安装阶段需要访问 Studio 的局域网分享，运行时使用公网网关。
2. 打开问全，确认目标和清单，开始访谈即可。**无需填写地址、访问码或导入 JSON**，网络和采集权限仍由 App 正常申请。
3. 安装后可关闭 Mac，不要求与 Mac 在同一 Wi-Fi。保持问全前台；暂停、离开或进入后台会停止采集。

此个人安装包按用户要求包含云端地址与网关访问码，拿到包的人可提取并使用该网关权限，因此只供本人安装，不作为公开发布包。火山和文本模型的上游 API Key 仍只在服务器。设置页保留手动更换服务；默认访问码只对预置的完整网关地址生效，不会发送给其他网关或路径。本机旧手动访问码为空时自动使用预置值。旧的回环地址自动迁移，访谈记录保留。

构建脚本从被 Git 忽略、权限 600 的 `.env.connection.json` 读取连接信息，仅写入生成的 `dist/config.js`、Studio 镜像与安装包；`web/config.js` 源文件不含真实访问码。普通 `npm run build` 和双击构建脚本都会生成免配置包；若私密文件缺失，则构建不含访问码的手动配置版并明确提示。不要将生成目录推送至公开仓库。

## 录音、转写与分析

- 默认连续采集，约每 200 ms 将音频送出，不等整段录完再上传。原生 16 kHz 单声道 Opus 做增量 Ogg 封装；云端网关保存凭证并与套餐专用 WebSocket 连接。
- 中间识别文字只更新预览；服务确认的稳定分句才保存和排队分析，重复分句去重，稳定文本被修订时撤回旧分析。若服务未提供时间戳，明确提示并保留文字，不虚构时间。
- 语言模型仍必需：ASR 负责声音转文字，模型对照目标、角色、清单和已有陈述发现缺口、生成追问。当前默认使用火山 Agent Plan `deepseek-v4.1-flash`，关闭深度思考，以 SSE 接收上游增量，再向手机转发 NDJSON。草稿只在手机展示，完整结果校验通过后才写入记录与眼镜。
- 暂停、停止、结束、离开访谈页、后台或设备断开均停止采集。手动停止会等尾包收尾；后台或离开会取消连接，保留已收到的稳定文字。不会在后台自动重启。
- 当前每次采集上限 1 小时；网络积压、SDK 丢帧或长时间无音频会明确停止并提示。完整转写留在访谈记录，发送给语言模型的是有限的近期上下文。
- 已用当前 Agent Plan 独立验证两种合成声音返回不同说话人编号，见 [说话人分离实测](docs/说话人分离可行性_2026-10-17.md)。当前 0.2.5 尚未接入编号与访谈角色的映射。
- **连续采集不等于完整音频归档。** 原始音频不写入问全后端磁盘；插件保存转写及来源。所有分句暂按当前手选角色标注，尚未自动区分访谈双方。ASR 稳定句也可能识别有误，可更正原话和角色。
- 文件回放限制 5 MiB / 2 分钟，先导入，明确点击“回放并流式识别”后才发送。回放按真实节奏发送，不播放到扬声器，也不打开麦克风。SDK 文件选择器会复制所选文件到宿主私有存储；“清除音频”只清除页面引用。

## 其他已实现交互

- 多主题、多次访谈，FDE、用户研究及自定义清单；会前确认目标和角色。
- 一条追问、原话依据、信息缺口与事项状态；“已问”只代表问题已提出，不自动判定已有答案。
- 跳过、稍后处理、暂停、恢复、结束；更正原话后撤回派生分析，再由用户核对和重新分析。

## 开发与配置

Node.js >= 22，本机已用 26.10.0。第三方运行依赖为 `ws`，锁定版本见 package-lock。官方 SDK 与打包器从相邻 `plugin-open-platform` 读取。

```sh
cd /Users/miao/Documents/Claudedesktop/极米/问全
npm ci
npm run build
npm run check
npm test
npm start
```

先构建再测试，显示测试使用打包 SDK。唯一编辑源为 `问全/web`；构建更新 `dist`、`release/wenquan-0.3.0.mmpkg`，以及官方 SDK 的 `PhoneSDK/examples/wenquan` 镜像和对应 dist 包。SDK 公共代码与参考示例未改。双击 `构建并打开Studio.command` 可构建并打开原生 Studio。

本机已在被 Git 忽略、权限为 600 的 `.env` 配置现有凭证，没有把 Key 放到插件包。新环境可复制 `.env.example`，参考 `profiles/volc-agent-plan.env.example`；`profiles/joymaas.env.example` 仅保留为历史兼容配置。火山配置：

```dotenv
ASR_PROVIDER=volcengine
VOLC_ASR_API_KEY=在本机配置现有套餐Key
VOLC_ASR_URL=wss://openspeech.bytedance.com/api/v3/plan/sauc/bigmodel_async
VOLC_ASR_RESOURCE_ID=volc.seedasr.sauc.duration
```

文本模型使用 Agent Plan 专用 `https://ark.cn-beijing.volces.com/api/plan/v3`，`MODEL_NAME=deepseek-v4.1-flash`、`MODEL_STREAM=true`、`MODEL_THINKING=disabled`、`MODEL_REPAIR=true`。`MODEL_API_KEY` 在服务端配置套餐 Key；不要换成按量计费 `/api/v3`。仅后端兼容 HTTP 文件转写需要 ffmpeg，原生流式 Opus 无需转码。保留了旧 OpenAI 兼容文件转写适配，当前主路径固定使用火山套餐地址，不回落到非套餐接口。

本机开发服务默认监听 `127.0.0.1:8787`；手机默认使用已部署的 HTTPS/WSS 网关。服务器配置位于 `/opt/wenquan/.env`，只将容器端口映射到服务器回环地址 `127.0.0.1:8788`，由现有 Caddy 的 `/wenquan/*` 路由代理，未开放额外公网端口。网关必须配置独立的 `GATEWAY_TOKEN`；手机请求携带设备访问码，服务再携带上游 API Key 调用火山及模型。

云端只提供 API（`SERVE_WEB=false`），允许携带访问码的不同 WebView 来源（`ALLOW_TOKEN_ORIGINS=true`）；HTTP、WebSocket 均鉴权，匿名请求返回 401。具体重建、运维、回滚和文件转写限制见 [deploy/README.md](deploy/README.md)。
