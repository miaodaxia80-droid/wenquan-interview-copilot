# 当前 Agent Plan 说话人分离实测

2026-10-17 使用既有套餐专属 Key 与专用双流地址 `wss://openspeech.bytedance.com/api/v3/plan/sauc/bigmodel_async` 完成独立测试。没有改动云端生产服务或已安装 0.2.4 插件。

请求沿用当前 16 kHz 单声道 PCM / 二遍识别，增加：

```json
{"enable_speaker_info":true,"show_utterances":true,"enable_nonstream":true,"ssd_version":"200"}
```

音频为项目内 Tingting 中文合成语音与 Daniel 英文合成语音串接，约 17.2 秒；未使用真人声纹注册。接口接受参数、正确转写两段，最终在 `result.utterances[].additions.speaker_id` 分别返回字符串 `0` 与 `1`。不能忽略 additions 层级；第一次诊断只检查其他字段未取得编号，修正提取路径后重新请求，最终结果见 `evidence/speaker-capability-probe.json`。

此测试证明当前套餐及配置能够返回不同说话人编号，不代表真人多人场景的分离准确率、重叠发言效果或跨录音身份稳定性已验证。编号不能直接说明真实姓名或业务角色。

建议接入路线：ASR 返回编号 → 前端保留编号和原始来源 → 本次会话内由用户映射访谈者/受访者 → 分角色提供模型上下文 → 支持更正映射并撤回受影响的旧分析。没有编号时标记未知，不能把音色判断当成已确认的业务角色；重开流后不可假定同编号仍是同一人。当前 0.2.4 仍按手选角色标注，尚未实现此映射。
