# 手机剧本演示预设（0.4.1）

在手机“访谈主题”页顶部点击“打开剧本演示预设”。自动填入《第一个陌生用户之后：一个校园工具为什么差点做不下去》的主题、目标、虚构嘉宾背景和访谈边界，四条主线为起点、转折、选择、后续，与 docs/演示访谈_两人剧本.md 一致。确认后点击“开始访谈”，开场自然介绍小林为主持人、小周为嘉宾。

预设仅包含会前准备，不预填转写、嘉宾答案、追问结果或会后归纳。重复点击继续未结束的预设访谈；已结束时新建一场，原记录保留。现场使用真实模型与自动角色识别，不切换固定结果的离线演示模式。
