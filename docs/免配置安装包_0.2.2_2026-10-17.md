# 问全 0.2.2 个人免配置版

用户要求将云端连接打入安装包，安装后直接使用。本版预置现有阿里云网关地址与设备访问码，无需导入 JSON 或手动填写。上游火山和文本模型 API Key 继续仅在服务器；网关服务不需要升级，仍为 0.2.1。

## 行为

- 新安装直接使用包内连接；升级时原有访谈记录保留，回环地址迁移到云端。
- 手动保存的非空访问码优先；无本机访问码或本机存储不可用时使用预置访问码。
- 预置访问码只匹配完整默认网关地址（包括路径），用户更改为其他网关或其他路径时不会携带此码。
- 设置入口保留，网络和录音权限正常由宿主申请，采集仍限前台。
- 普通构建从忽略的 `.env.connection.json` 注入生成的 `dist/config.js`；源文件中的默认访问码为空。私密配置缺失时明确生成手动配置版，无法读取或访问码无效则取消构建。

此个人安装包能够提取网关访问码，拿到包的人可能使用当前网关额度。因此只供本人使用，不上传公开仓库或公开分发。该限制是预置静态凭证的实际属性，不把访问码混淆为服务端上游 API Key。
