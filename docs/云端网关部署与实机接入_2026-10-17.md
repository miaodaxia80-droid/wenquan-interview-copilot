# 0.2.1 云端网关与手机独立运行

日期：2026-10-17。源码工作树未提交、推送或公开发布。服务已部署到用户指定的阿里云服务器。

## 故障与修正

原版默认 `http://127.0.0.1:8787`，在手机上指向手机自身，并不能访问 Mac 的 Node 服务。因此同一 Wi-Fi 也无法解决该地址问题。用户看到的 Fetch 错误没有手机调试日志，不能把所有潜在证书、跨域或权限问题都认定为已排除。

0.2.1 手机默认地址为 `https://cx.kevinxu.cn/wenquan`，旧的回环地址自动迁移。真实手机拒绝保存回环或非 HTTPS 网关，HTTP 和 WebSocket 均保留网关路径前缀；ASR 自动使用 WSS。连接错误展示当前来源及网络、HTTPS 和权限检查提示。

手机 WebView 继续运行采集、状态、记录与业务界面。云端网关负责保存上游密钥、设置火山 WebSocket 鉴权头并代理流式音频和模型请求。浏览器标准 WebSocket 构造参数没有自定义请求头；火山官方接口要求鉴权头，因此不能直接把原有 Node 网关移动到 WebView。

参考：[火山 Agent Plan 语音接口](https://ark.volcengine.com/region:cn-beijing/docs/agent-plan-personal-voice-model)、[WebSocket 标准](https://websockets.spec.whatwg.org/)。

## 部署与凭证

独立 Compose 服务位于 `/opt/wenquan`，容器回环端口 `8788`，公网复用 Caddy 的 `/wenquan/*` 路由。未修改其他项目；部署后原有 `https://cx.kevinxu.cn/` 返回 HTTP 200，问全容器健康，观测内存约 35 MiB（256 MiB 上限）。

上游凭证仅在服务器权限 600 的 `.env`。HTTP API 使用设备访问码鉴权，WebSocket 在首条消息鉴权后才连接上游。访问码不会出现在 URL、MMPKG 或访谈记录；手机存于独立 localStorage，不使用会记录参数的宿主 Bridge 存储。支持不同移动 WebView 来源的预检，但实际请求仍需访问码。

## 用户实机复测

1. 使用 Studio 当前 **0.2.1** 二维码更新插件，确认手机端确实替换了旧版本。
2. “分析设置 → 粘贴连接配置”，使用本机私密 `.env.connection.json`，点“填入连接配置 → 检测连接 → 保存设置”。访问码不应发送到聊天或公开。
3. 允许所需网络与采集权限；先导入合成音频并回放，观察转写、已分析和一条追问。
4. 再在已允许记录的现场开始访谈，验证持续录音。安装和配置完成后关闭 Mac，分别以 Wi-Fi 或移动网络验证独立运行。
5. 若失败，反馈新版号、发生在检测/录音/分析哪一步，以及页面显示的错误；不反馈访问码或 API Key。

保持前台才会采集。锁屏、后台持续录音、多说话人区分、独立准确率评估及用户研究均未在本轮完成。
