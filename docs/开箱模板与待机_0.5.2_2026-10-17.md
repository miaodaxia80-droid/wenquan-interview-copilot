# 问全·实时访谈助手 0.5.2：开箱模板与待机

日期：2026-10-17。基线为已发布的 v0.5.1，提交 b2e1380011bdf0abc9661b01e56b6bde416b9203。0.5.1 的 main 与标签已推送至 GitHub；本轮在 feat/0.5.2-interview-templates 分支开发。

## 改动

- 产品名称统一为“问全·实时访谈助手”，手机、眼镜页脚、manifest、设计预览同步更新；插件 ID 和本地存储键保持兼容。
- 访谈主题页删除“体验示例 · 两人剧本”与预设创建入口。历史用户记录与历史文档保留。
- 新增人物经历（30 分钟）、用户研究（25 分钟）、需求澄清（40 分钟）、项目复盘（30 分钟）、专业观点（30 分钟）五个模板。每个包含主题、目标、4–5 条主线、每条主问题及两个可编辑准备问题。使用模板新建独立数据，不预填回答、不自动录音。
- 五个模板均使用 v2 实时访谈流程，初始章节取模板实际第一条主线；保留旧 v1 记录和兼容模板。
- 眼镜：已确认访谈、无候选时显示低亮度“安静聆听”与真实当前主线；有候选时显示现有大字短问句；未开始、暂停、结束时全黑。静态画面，无闪烁或虚构录音状态。待机不计入问题送达指标。

## 实际验收

- npm run check、npm run build 通过。
- npm test：108/108 通过，含五模板上下文与分析兼容、模板数据独立性、旧记录兼容、入口操作、待机与暂停/结束优先级。
- git diff --check 通过。
- 浏览器 818px 桌面及 390px 手机宽度均无横向溢出；恰好五个模板，体验示例入口不存在。使用需求澄清模板后，40 分钟与五条主线、预设问题均已填好。
- 原生 Studio 已加载 0.5.2 与官方 GM Web Bridge v2，显示“推荐组合：眼镜协议完全匹配”。
- 独立虚构记录“问全 0.5.2 需求模板与待机验收（虚构）”：文本演练无候选时实际显示待机；20:10:56 两块图像均返回 presented:true。
